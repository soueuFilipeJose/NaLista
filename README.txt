NaLista — landing page de eventos
=================================

Arquivos:
- index.html: estrutura da página
- styles.css: identidade visual e responsividade
- script.js: menu mobile, filtros e busca
- assets/logo.png: logotipo otimizado
- assets/favicon.png: ícone do navegador
- assets/logo-original.png: arquivo original do logo usado no projeto

Como abrir:
1. Extraia o ZIP.
2. Abra index.html em qualquer navegador moderno.

Não há dependências externas. O projeto funciona offline.
